# Contribution Rules

1. Create a feature branch.
2. Work in your assigned feature folder.
3. Reuse shared components.
4. Do not change the database/API contract without coordinating with the technical lead.
5. Add/update tests where relevant.
6. Open a Pull Request.
7. Another student reviews.
8. Coordinator/integration lead approves the merge.

## Shared core

Changes to `src/App.jsx`, `src/routes.jsx`, `src/layouts/`, `src/components/ui/`, `src/services/`, database migrations, or global styles should be treated as shared-core changes and discussed before merging.
